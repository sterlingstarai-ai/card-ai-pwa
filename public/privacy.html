개인정보처리방침

시행일: 2026년 1월 18일 · 개정일: 2026년 6월 13일

서비스명: Card AI | 문의: sterling.star.ai@gmail.com

1. 목적

Card AI 운영자(이하 "운영자")는 Card AI 서비스(이하 "서비스") 이용 과정에서 이용자의 개인정보를 최소한으로 처리하며, 관련 법령(개인정보 보호법 등)을 준수합니다. 본 방침은 운영자가 어떤 정보를 어떤 목적으로, 어떤 방식으로 처리하는지 설명합니다.

2. 처리하는 정보의 항목

서비스는 원칙적으로 이용자를 직접 식별할 수 있는 정보를 요구하지 않으며, 다음과 같은 정보만을 제한적으로 처리할 수 있습니다.

2.1 이용자가 직접 제공하는 정보

정보 수정 제보 제출 시:

  • 필수: 제보 유형, 제보 내용
  • 선택: 연락처 이메일, 출처 링크
중요: 제보 내용에 카드번호, 주민번호, 주소, 정확한 위치, OCR 인식 원문 등 민감/개인정보를 입력하지 마십시오. 운영자는 입력을 제한·마스킹할 수 있으나, 이용자가 입력한 정보에 대한 1차 책임은 이용자에게 있습니다.

2.2 자동 생성·수집되는 정보(진단/로그)

서비스 안정성 및 오류 대응을 위해 아래 정보가 자동 수집·전송될 수 있습니다:

  • 앱 버전/빌드 정보
  • 플랫폼 정보: web / iOS / Android
  • 브라우저 정보, 언어, 시간대
  • 네트워크 상태: online 여부
  • 권한 상태: 위치 권한 granted/denied/prompt
  • 화면/컨텍스트 정보: 선택된 장소/카드 식별자
  • 익명 식별자(anonUserId): 기기 로컬에 생성된 UUID (중복/스팸 제보 방지 목적)
  • 위치 좌표(GPS): 이용자가 위치 권한을 허용하고 "주변 장소" 검색을 사용할 때, 검색 수행을 위해 Kakao 및 운영자 프록시로 전송됩니다(검색에만 사용, 운영자 서버에 저장하지 않음).
  • 이미지: 카드 인식(OCR)을 사용할 때, 분석을 위해 Google Cloud Vision으로 전송됩니다(인식에만 사용, 저장하지 않음).

2.3 수집·저장하지 않는 정보

운영자는 아래 정보를 운영자 서버에 수집·저장하지 않습니다. 일부 항목은 기능 수행을 위해 외부 처리위탁으로 일시 전송될 수 있으며(저장하지 않음), 자세한 내용은 5항을 참조하십시오:

  • 카드번호, 주민번호, 계좌번호, 상세 주소, 전화번호 (수집·전송하지 않음)
  • OCR 인식 텍스트 원문 (운영자 서버로 전송·저장하지 않음)
  • 카드 인식용 이미지 (OCR 처리를 위해 Google Cloud Vision으로 일시 전송되나 저장하지 않음)
  • 정확한 GPS 좌표 (주변 장소 검색 시 Kakao로 일시 전송되나 저장하지 않음)

3. 처리 목적

  • 서비스 제공 및 기능 수행 (혜택 추천, 로컬 카드 관리 등)
  • 오류 분석, 장애 대응, 품질 개선
  • 데이터 정확성 개선을 위한 제보 처리
  • 스팸/남용 방지

4. 보관 및 이용 기간

  • 제보 데이터: 제보 처리 및 이력 관리 목적 달성 시까지 보관
  • 진단 로그: 오류 분석에 필요한 기간 동안 보관 후 삭제/익명화
  • 로컬 데이터: 이용자 기기에 저장되며, 앱/브라우저 데이터 삭제 시 제거

5. 제3자 제공 및 처리위탁

운영자는 서비스 운영을 위해 일부 데이터를 외부 서비스(처리위탁)로 전송할 수 있습니다:

  • GitHub Issues: 사용자 제보 접수/추적
  • Vercel: 서비스 호스팅 (서버 로그 일부 생성 가능)
  • Google Cloud Vision: 카드 인식(OCR) 처리를 위한 이미지 분석 (이미지는 인식 처리에만 사용되며 운영자 서버에 저장하지 않음)
  • Kakao(카카오): 주변 장소 검색을 위한 위치 기반 장소 조회
  • Firebase Analytics(Google) · Mixpanel: 익명 사용 통계/이벤트 분석 (예: 선택한 장소/카드 식별자, 익명 세션 식별자). 아래 6-1의 동의가 있는 경우에만 전송
  • Sentry: 오류·안정성 모니터링 (텍스트/미디어는 마스킹). 세션 리플레이는 동의가 있는 경우에만 수집

위 분석 도구는 광고 식별이나 제3자 광고 목적의 추적에 사용하지 않습니다.

5-1. 분석 동의 (선택)

Firebase/Mixpanel을 통한 익명 사용 통계 및 Sentry 세션 리플레이는 기본적으로 비활성화되어 있으며, 최초 실행 시 안내 후 이용자가 명시적으로 동의한 경우에만 수집·전송됩니다. 동의하지 않아도 모든 핵심 기능을 동일하게 이용할 수 있습니다. (오류 보고를 위한 기본 진단 정보는 안정성 확보를 위해 마스킹된 형태로 처리될 수 있습니다.)

6. 이용자의 권리

이용자는 관련 법령이 허용하는 범위에서 개인정보 열람, 정정, 삭제, 처리정지를 요구할 수 있습니다. 문의처로 요청 시 본인 확인 후 처리합니다.

단, 서비스는 회원가입 없이 익명 기반으로 동작하여 이용자 식별이 어려운 경우 권리 행사가 제한될 수 있습니다.

7. 안전성 확보 조치

  • 개인정보 최소 수집 원칙
  • 민감정보 입력 금지 및 마스킹 규칙 적용
  • 요청 빈도 제한(rate limit), 길이 제한 등 남용 방지
  • 접근권한 관리 및 비밀정보 환경변수 분리

8. 아동(만 14세 미만)

서비스는 만 14세 미만 아동을 대상으로 하지 않습니다. 아동의 개인정보가 수집된 사실을 인지한 경우 지체 없이 삭제합니다.

9. 방침 변경

본 방침이 변경될 경우, 서비스 내 공지를 통해 시행일 및 변경 내용을 안내합니다.

앱스토어 심사용 요약:
본 서비스는 카드번호, 주민번호, OCR 원문 텍스트를 수집·전송하지 않으며, 정확한 위치 좌표와 카드 인식용 이미지를 운영자 서버에 저장하지 않습니다. 다만 기능 수행을 위해 카드 인식용 이미지는 Google Cloud Vision으로, 위치 좌표는 주변 장소 검색 시 Kakao로 일시 전송됩니다(저장하지 않음). 오류 분석을 위해 기기/브라우저 진단 정보와 익명 식별자(UUID)를 사용할 수 있습니다. 익명 사용 통계(Firebase·Mixpanel)와 세션 리플레이(Sentry)는 이용자가 동의한 경우에만 수집하며, 광고 목적의 추적은 하지 않습니다.
